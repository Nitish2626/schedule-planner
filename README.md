A simple and responsive schedule planner built with React and Vite. It helps you manage daily tasks, search through your list, and keep track of important updates with a clean interface.

![Tailwind](https://img.shields.io/badge/Tailwind-4.x-06B6D4)

## Why this project

This project was created to make daily planning easier, faster, and more organized. It gives users a clean way to manage tasks without needing a heavy app or complicated setup. The goal is to keep schedules simple, accessible, and easy to update whenever priorities change.

## Features

- Add new schedule items
- Search tasks instantly
- Edit existing tasks
- Delete tasks from the list
- Save data locally using browser storage
- Responsive layout for desktop and mobile devices
